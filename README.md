# NASA-PLANET-Explorer
## Project Idea 
NASA Planet Explorer is simple educational website that allows users to learn basic information about planets in our solar system 

The project helps make space information simple and accessible for students and people interested in space 

## Technologies Used

-HTML
-CSS
-JavaScript
-GitHub

## How to Run the project 
1.)Download or clone the repository 
2.)open the project folder 
3.)open index.html in web browser
4.)select a planet to view information about it
